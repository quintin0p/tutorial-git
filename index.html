O que é o Git?

O Git é um sistema de controle de versão distribuído, criado por Linus Torvalds em 2005. Ele permite registrar, acompanhar e gerenciar as alterações realizadas nos arquivos de um projeto ao longo do tempo. Com ele, você pode consultar versões anteriores do seu código, recuperar alterações, criar ramificações para desenvolver novas funcionalidades e colaborar com outras pessoas sem precisar manter várias cópias manuais do mesmo projeto.

Principais comandos do Git

git init

Inicializa um repositório Git no diretório atual.

git init

Utilize quando quiser começar a controlar as versões de um projeto existente.


git clone

Cria uma cópia local de um repositório remoto.

git clone https://github.com/usuario/projeto.git

Ideal para baixar um projeto hospedado no GitHub.


git status

Mostra o estado atual do repositório, incluindo arquivos modificados e alterações preparadas para commit. 

git status

git add

Adiciona alterações à área de preparação (staging area).

git add index.html

Para preparar todas as alterações rastreáveis do diretório atual:

git add .

git commit

Registra as alterações preparadas no histórico local.

git commit -m "Adiciona página inicial"

git push

Envia os commits locais para um repositório remoto configurado.

git push

git pull

Busca alterações remotas e tenta integrá-las à branch atual.

git pull
